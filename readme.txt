# Neuromorphic Materials Calculator 2025 (NMC2025)

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.17143512.svg)](https://doi.org/10.5281/zenodo.17143512)

NMC2025 is an educational and research tool that integrates quantum simulation workflows with AI-guided tutoring.  
It allows students and researchers to set up, run, and analyze materials simulations (e.g., DFT, tight-binding, transport) with interactive support.

---

## Features
- Automated generation of input files for **Quantum ESPRESSO**.
- AI-guided simulation recommendations (via Perplexity API).
- Preconfigured Python modules for band structures and DOS.
- Prepackaged with `.bat` launchers for easy Windows execution.
- Educational case studies and tutorials.

---

## Installation (Windows)

1. Download the latest release from [Zenodo](https://doi.org/10.5281/zenodo.17143512) or GitHub.
2. Extract the package to a local folder, e.g. `C:\NMC2025\`.
3. And run the installer
